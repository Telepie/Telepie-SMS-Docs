Send a single SMS message using an approved template.

### Headers

| Name            | Type   | Description                                         |
| --------------- | ------ | --------------------------------------------------- |
| `Authorization` | string | `Bearer YOUR_API_KEY`                               |
| `Content-Type`  | string | This should be set to `application/json`.           |

#### Request Body Parameters

<ParamField body="templateId" type="string" required>
  The approved SMS template ID.
</ParamField>

<ParamField body="headerId" type="string" required>
  The approved SMS Header ID.
</ParamField>

<ParamField body="type" type="string" required>
  Determines whether a single or multiple recipients are being targeted. Use
  `"single"` for a single recipient. `contact` is required and `contacts` must
  not be provided.
</ParamField>

<ParamField body="contact" type="string" required>
  Recipient phone number in E.164 format. Must start with `+91` followed by
  exactly 10 digits for India. Landline numbers are not supported.
</ParamField>

<ParamField body="vars" type="object">
  Template variables grouped by recipient phone number. If provided, it must
  contain an entry matching the value of `contact`. May be omitted when the
  selected template has no variables.
</ParamField>

#### Template Variables

Variables are mapped using the recipient's phone number as the key. Each object
may contain any number of variables supported by the selected template.

```json
{
  "+919876543210": {
    "var1": "John",
    "var2": "Order #1001"
  }
}
```

If no template variables are required, the `vars` field may be omitted.

<CodeGroup>

```json SampleRequest.json
{
  "templateId": "1707175000000000001",
  "headerId": "SMSHDR1",
  "type": "single",
  "contact": "+919876543210",
  "vars": {
    "+919876543210": {
      "var1": "Alice",
      "var2": "Telepie"
    }
  }
}
```

```json SampleResponse.json
{
  "operationId": "op00000000000001",
  "batch": {
    "id": "bt00000000000001",
    "type": "single"
  },
  "summary": {
    "total": 1,
    "accepted": 1
  },
  "messages": [
    {
      "messageId": "ms00000000000001",
      "contact": "+919876543211",
      "status": "accepted",
      "acceptedAt": "2026-08-12T05:38:00.000Z"
    }
  ]
}
```

</CodeGroup>

<Tip>
  A successful `202 Accepted` response only indicates that the request has been
  accepted for processing. It does not guarantee message delivery.
</Tip>

#### Success Response

| Field                    | Type   | Description                                    |
| ------------------------ | ------ | ---------------------------------------------- |
| `operationId`            | string | Unique identifier for this API operation.      |
| `batch.id`               | string | Batch identifier generated by the platform.    |
| `batch.type`             | string | Either `single` or `bulk`.                     |
| `summary.total`          | number | Total messages received in the request.        |
| `summary.accepted`       | number | Number of messages accepted for processing.    |
| `messages[].messageId`   | string | Unique message identifier.                     |
| `messages[].contact`     | string | Recipient phone number.                        |
| `messages[].status`      | string | Initial processing status.                     |
| `messages[].acceptedAt`  | string | ISO UTC timestamp of acceptance.               |
