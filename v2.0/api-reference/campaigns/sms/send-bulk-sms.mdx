Send bulk SMS messages to multiple recipients using an approved template.

### Headers

| Name            | Type   | Description                                         |
| --------------- | ------ | --------------------------------------------------- |
| `Authorization` | string | `Bearer YOUR_API_KEY`                               |
| `Content-Type`  | string | This should be set to `application/json`.           |

#### Request Body Parameters

<ParamField body="templateId" type="string" required>
  The approved SMS template ID.
</ParamField>

<ParamField body="headerId" type="string" required>
  The approved SMS Header ID.
</ParamField>

<ParamField body="type" type="string" required>
  Determines whether a single or multiple recipients are being targeted. Use
  `"bulk"` for multiple recipients. `contacts` is required and `contact` must
  not be provided.
</ParamField>

<ParamField body="contacts" type="string[]" required>
  List of recipient phone numbers in E.164 format, each starting with `+91`
  followed by exactly 10 digits for India. Maximum of **100** recipients per
  request.
</ParamField>

<ParamField body="vars" type="object">
  Template variables grouped by recipient phone number. Every recipient in
  `contacts` must have a matching entry, and no additional phone numbers are
  allowed inside `vars`. May be omitted when the template has no variables.
</ParamField>

#### Template Variables

Variables are mapped using the recipient's phone number as the key.

```json
{
  "+919876543210": {
    "var1": "John",
    "var2": "Order #1001"
  }
}
```

If no template variables are required, the `vars` field may be omitted.

<CodeGroup>

```json SampleRequest.json
{
  "templateId": "1707175000000000001",
  "headerId": "SMSHDR1",
  "type": "bulk",
  "contacts": [
    "+919876543210",
    "+919999999999",
    "+918888888888"
  ],
  "vars": {
    "+919876543210": {
      "var1": "Alice",
      "var2": "Order #1001"
    },
    "+919999999999": {
      "var1": "Bob",
      "var2": "Order #1002"
    },
    "+918888888888": {
      "var1": "Carol",
      "var2": "Order #1003"
    }
  }
}
```

<Tip>
  A successful `202 Accepted` response only indicates that the request has been
  accepted for processing. It does not guarantee message delivery.
</Tip>

#### Success Response

| Field                    | Type   | Description                                    |
| ------------------------ | ------ | ---------------------------------------------- |
| `operationId`            | string | Unique identifier for this API operation.      |
| `batch.id`               | string | Batch identifier generated by the platform.    |
| `batch.type`             | string | Either `single` or `bulk`.                     |
| `summary.total`          | number | Total messages received in the request.        |
| `summary.accepted`       | number | Number of messages accepted for processing.    |
| `messages[].messageId`   | string | Unique message identifier.                     |
| `messages[].contact`     | string | Recipient phone number.                        |
| `messages[].status`      | string | Initial processing status.                     |
| `messages[].acceptedAt`  | string | ISO UTC timestamp of acceptance.               |
