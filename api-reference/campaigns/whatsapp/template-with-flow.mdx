Use this endpoint to send a WhatsApp template message that includes a flow.

#### Required attributes

<ParamField body="from" type="string" required>
  The number registered with WhatsApp business from which the message is to be
  sent. Ensure that the country code is prefixed to the number. For example, if
  the number is in the India, the format would be: +91XXXXXXXXXX
</ParamField>

<ParamField body="templateName" type="string" required>
  This template name contains only lowercase alphanumeric characters and
  underscores.
</ParamField>

<ParamField body="to" type="string" required>
  Recipient’s MSISDN
</ParamField>

<ParamField body="type" type="string" required>
  WhatsApp message templates type
</ParamField>

<ParamField body="components" type="string" required>
  To build a message content object for WhatsApp, typically include various
  fields such as param, header type(text, images, video, and other media).
</ParamField>

#### Optional attributes

<ParamField body="campaignName" type="string">
  The WhatsApp campaign name refers to the specific name or title given to a
  campaign conducted through WhatsApp
</ParamField>

<CodeGroup>

```json SampleRequest.json
curl -P - /v1/whatsapp\
  -H 'apikey':'string'
  -H "Content-Type: application/json" \
  -d '{
      "from": "+91XXXXXXXXXX ",
      "campaignName": "api-flow",
      "to": "+91XXXXXXXXXX",
      "templateName": "template_name",
      "components": {
          "buttons": {
              "flow": [
                  0
              ],
              "params": [
                  "https://xyz.com/"
              ]
          }
        },
      "type": "template"
    }'
```
