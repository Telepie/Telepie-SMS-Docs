This endpoint is used to create a rich text RCS template.

#### Required attributes

<ParamField body="botId" type="array" required>
  Identifier of the RCS bot associated with the template.
</ParamField>

<ParamField body="templateName" type="string" required>
  Unique name of the template.
</ParamField>

<ParamField body="templateType" type="string" required>
  Use <code>text</code>.
</ParamField>

<ParamField body="isRichText" type="boolean" required>
  Set to <code>true</code> for a rich text template.
</ParamField>

<ParamField body="content.plainText" type="string" required>
  Text content of the template. Dynamic variables can be defined using `{{1}}`, `{{2}}`, etc.
</ParamField>

<CodeGroup>

```json SampleRequest.json
curl --location '/v1/rcs/template' \
--header 'apikey: YOUR_API_KEY' \
--header 'Content-Type: application/json' \
--data '{
  "botId": ["YOUR_BOT_ID"],
  "templateName": "welcome_rich_text",
  "templateType": "text",
  "isRichText": true,
  "content": {
    "plainText": "Hello {{1}}, welcome to Azmarq Omni Channel. Thank you for choosing us. Explore offers, track orders, and get support anytime from your messaging inbox. We are glad to have you with us and look forward to serving you better every day.",
    "sampleVariable": ["John"]
  }
}'
```

</CodeGroup>
