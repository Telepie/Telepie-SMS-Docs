---
title: Update Standalone Template
description: "This endpoint updates an existing standalone rich card template."

playground: true
---

This endpoint updates an existing standalone rich card template.

The **templateType** must remain **standalone**.

#### Required attributes

<ParamField body="templateName" type="string" required>
  Unique identifier of the existing template.
</ParamField>

<ParamField body="botId" type="array" required>
  Identifier of the RCS bot.
</ParamField>

<ParamField body="templateType" type="string" required>
  Must be <code>standalone</code>.
</ParamField>

<ParamField body="mediaType" type="string" required>
  Media type used by the rich card.
</ParamField>

<ParamField body="content.richCardDetails" type="object" required>
  Updated standalone rich card configuration.
</ParamField>
