This endpoint is used to create a RCS carousel template where each card can have its own dynamic title and description.

Each carousel card can contain:

- Dynamic title and description values
- Media such as images
- Reply or action suggestions
- Static or dynamic content using template variables

#### Required attributes

<ParamField body="botId" type="array" required>
  Identifier of the RCS bot associated with the template.
</ParamField>

<ParamField body="templateName" type="string" required>
  Unique name of the carousel template.
</ParamField>

<ParamField body="templateType" type="string" required>
  Use <code>carousel</code> for a carousel template.
</ParamField>

<ParamField body="isRichText" type="boolean" required>
  Defines whether the template supports rich content.
</ParamField>

<ParamField body="mediaType" type="string" required>
  Defines the media type used by the carousel cards. For image cards, use <code>IMAGE</code>.
</ParamField>

<ParamField body="content.richCardDetails.carousel.cardWidth" type="string" required>
  Defines the width of the carousel cards. For example, <code>MEDIUM_WIDTH</code>.
</ParamField>

<ParamField body="content.richCardDetails.carousel.contents" type="array" required>
  List of cards included in the carousel. Each card can have its own title, description, media, and suggestions.
</ParamField>

<ParamField body="params" type="array" required>
  Provides the values used for dynamic variables in the corresponding card content.
</ParamField>

#### Dynamic variables

Dynamic variables can be defined using `{{1}}`, `{{2}}`, etc.

The values for these variables are provided through the **params** array of each card.

For example:

<ParamField body="{{1}}" type="string" required>
  Replaced with the corresponding title value from the card's params.
</ParamField>

<ParamField body="{{2}}" type="string" required>
  Replaced with the corresponding description value from the card's params.
</ParamField>
