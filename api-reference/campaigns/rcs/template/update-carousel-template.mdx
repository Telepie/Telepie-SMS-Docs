This endpoint updates an existing carousel template.

The **templateType** must remain **carousel**.

#### Required attributes

<ParamField body="templateName" type="string" required>
  Unique identifier of the existing carousel template.
</ParamField>

<ParamField body="botId" type="array" required>
  Identifier of the RCS bot.
</ParamField>

<ParamField body="templateType" type="string" required>
  Must be <code>carousel</code>.
</ParamField>

<ParamField body="mediaType" type="string" required>
  Media type used by the carousel.
</ParamField>

<ParamField body="content.richCardDetails.carousel" type="object" required>
  Updated carousel configuration and card contents.
</ParamField>
