Same suffix rule as standalone. Compact `openUrl` values fill carousel card Open URL placeholders in order.

#### Required attributes

<ParamField body="number" type="string" required>
  Recipient's phone number (must be RCS-enabled and in international format).
</ParamField>

<ParamField body="templateName" type="string" required>
  Name of the carousel template to be used.
</ParamField>

<ParamField body="botId" type="string" required>
  Identifier of the RCS bot used to send the message.
</ParamField>

<ParamField body="content" type="array" required>
  Per-card `params` and optional `fileUrl`. Use `openUrl` for path suffixes, or `cardSuggestions` to override chips per card.
</ParamField>

<CodeGroup>

```json SampleRequest.json
curl --location '/v1/rcs' \
--header 'apikey: YOUR_API_KEY' \
--header 'Content-Type: application/json' \
--data '{
"botId": "YOUR_BOT_ID",
"number": "+91XXXXXXXXXX",
"templateName": "product_carousel",
"campaignName": "rcs-api-sms",
"content": [
{
  "card": [
    {
      "index": 0,
      "params": [
        { "title": ["Urban"] },
        { "description": ["John"] }
      ]

    { "url": "headphones-1001" }
  ]
}
]
}'
```
